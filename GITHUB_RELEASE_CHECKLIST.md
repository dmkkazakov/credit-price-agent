# GitHub release checklist

- [ ] Create public repository `credit-price-agent`
- [ ] Push repository contents
- [ ] Confirm `make experiment` reproduces `results/metrics.json`
- [ ] Confirm `make test` passes
- [ ] Add repository URL to `paper/manuscript.md`, PDF/DOCX, and `CITATION.cff`
- [ ] Create v0.1.0 release
- [ ] Optionally archive release in Zenodo for a DOI
- [ ] Upload final manuscript to SSRN
- [ ] Never add proprietary data, internal model parameters, screenshots, or employer-confidential material
