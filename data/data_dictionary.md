# Synthetic data dictionary

All monetary values are synthetic and have no mapping to any institution.

| Field | Meaning |
|---|---|
| month | Monthly simulation index |
| industry | Synthetic corporate sector |
| revenue | Synthetic revenue scale |
| ebitda_margin | EBITDA / revenue |
| leverage | Synthetic debt leverage |
| interest_cover | Interest coverage ratio |
| relationship_years | Length of bank relationship |
| repayment_score | Synthetic repayment-quality signal |
| previous_accept | Historical acceptance propensity |
| market_rate | Simulated market reference rate |
| funding_spread | Simulated marginal funding spread |
| liquidity_pressure | Bank liquidity state, 0–1 |
| capital_pressure | Bank capital state, 0–1 |
| sector_pressure | Sector-concentration state, 0–1 |
| pd_true / lgd_true | Latent synthetic risk parameters |
| amount | Requested amount |
| tenor_years | Loan tenor |
| offered_rate | Historical synthetic quote |
| accepted | Synthetic acceptance outcome |
| default | Synthetic default outcome |
